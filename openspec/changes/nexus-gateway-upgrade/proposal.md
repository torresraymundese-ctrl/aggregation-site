# Nexus Gateway 聚合网关升级提案

状态：核心阶段已应用并归档；团队管理和协议扩展转入后续变更。

## 动机

现有系统已经具备统一网关、余额、API Key 和管理后台，但资金正确性、真实指标、模型分层和团队治理尚不足以支撑公开商业使用。

## 已确认方案

1. 先修安全、支付、退款、计费和页面真实性。
2. 一个逻辑模型关联多个等价供应商接入点，只在请求前选择一次。
3. 上游失败直接返回，不静默替换模型或二次改道。
4. 未取得书面转售授权前优先提供 BYOK。
5. 分阶段增加模型广场、请求账本、工作空间和协议能力。

## 验收

以后端测试、前端构建与冒烟、支付并发测试、计费样例、路由确定性和权限隔离测试为准。
